> **Python command (platform dependent):** the examples use `python3` (Linux/macOS). **On Windows** `python3` often does not exist — or it is the Microsoft Store stub that opens the Store —, therefore `python` or `py -3` is the correct call there. If `python3` gives a "command not found" / "not recognized" error, **retry with `python`, then with `py -3`**, using the same parameters. This is not an error of the script, and it is no reason to stop.
